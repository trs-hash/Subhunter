# SUBHUNTER — сайт школи BJJ

Статичний сайт-візитка для GitHub Pages. Один файл `index.html`, без збірки.

## Деплой на GitHub Pages з власним доменом

1. Створи репозиторій (наприклад `subhunter-site`), залий `index.html`, `robots.txt`, `sitemap.xml`, `CNAME`.
1. Settings → Pages → Source: `main` branch, root.
1. Файл `CNAME` вже містить `subhunter.com.ua`.
1. У реєстратора домену додай DNS-записи:
- `A` записи на IP GitHub Pages: 185.199.108.153 / .109. / .110. / .111.153
- `CNAME` для `www` → `<твій-нікнейм>.github.io`
1. У Settings → Pages увімкни **Enforce HTTPS** (після видачі сертифіката).

## Що замінити перед запуском

- `https://t.me/username` — реальний Telegram (5 місць, пошук по “t.me”).
- Логотип-заглушка (SVG у шапці) → реальний `logo.svg`.
- Розклад (секція `#schedule`) — зараз заглушка.
- Ціни (секція `#prices`) — зараз заглушка.
- Тренери (секція `#coaches`) — фото та імена.
- `og-cover.jpg` — картинка 1200×630 для шерингу в соцмережах.

## Після запуску (SEO)

- Додай сайт у Google Search Console (підтвердження через DNS), відправ sitemap.
- Створи/прив’яжи профілі Google Business Profile для обох залів — це головний канал для запитів “джиу-джитсу поруч”.
